# Fichiers à déposer ici

Mets tes 3 fichiers dans ce dossier avec **exactement** ces noms :

| Fichier            | Contenu                        | Conseils                          |
|--------------------|--------------------------------|-----------------------------------|
| `photo-elle.jpg`   | Photo d'elle                   | carrée si possible, ~600×600 px   |
| `photo-toi.jpg`    | Photo de toi                   | carrée si possible, ~600×600 px   |
| `musique.mp3`      | Musique de fond                | format .mp3, garde-le léger (<4 Mo)|

Si un fichier manque :
- photo absente → une initiale colorée s'affiche à la place (rien ne casse) ;
- musique absente → le bouton musique ne s'affiche pas.

Pour changer l'initiale du fallback ou les noms affichés, édite `index.html`
(cherche `data-initial` et `figcaption`).
